# 🛡️ antihogu-insu (호구방지위원회 - 보험 호구 방지)

> **"전 국민 눈탱이 방지 프로젝트"**  
> 복잡한 보험 약관과 설계사의 공포 마케팅을 초등학교 4학년(10살)도 비웃을 수 있는 직관적인 언어로 해체하고, 내 증권의 거품과 시한폭탄을 10초 만에 잡아내는 **Zero-Privacy 보험 분석기 & ELI10 위키**.

---

## ✨ 핵심 기능

1. **🔒 Zero-Privacy 로컬 스캐너**:
   - 로그인 0초, 본인인증 0원, 주민번호 0개!
   - 서버 전송 0바이트, 100% 브라우저 로컬 메모리에서 구동되는 완벽한 개인정보 철벽 방어.
2. **🏷️ 호구 등급 도장 쾅!**:
   - `🛡️ 철벽 방어왕` / `🐥 알뜰 실속러` / `🍯 호구 꿈나무` / `👑 보험사 VIP 기부천사 1급`
3. **🐥 ELI10 사이다 팩트 폭격**:
   - "20년 동안 떡볶이 500그릇 값을 내는데, 아플 때 떡볶이 100그릇 값만 돌려받는 적자 계약입니다."
4. **✂️ 다이어트 처방전**:
   - 빼야 할 갱신형 시한폭탄과 푼돈 특약을 짚어주고, 매달 굳는 돈(치킨 N마리 값)을 계산.
5. **📖 보험 ELI10 위키**:
   - 증권에 적힌 난해한 한자어를 0.1초 만에 검색하고 3색 신호등 판정 뱃지로 확인.
6. **🩺 병원 & 청구 실전 시크릿 (Real Claim Hacks)**:
   - MRI 200만 원 100% 환급받는 입원의 법칙, 진단서 코드 한 글자(`G40` vs `I63`)로 2,000만 원 살려내는 의사 소통법.
