# 🚨 보험 119 (antihogu-insu)

> **"감기는 내 돈으로 내도 되지만, 이건 없으면 집안이 무너집니다."**  
> 설계사의 공포 마케팅과 수백 가지 조미료 특약을 걷어내고, 인생의 치명적 재앙(수천만 원 병원비, 수억 원 대물사고, 교도소 구속, 누수 파산)을 100% 막아주는 **6대 필수 메인 계약 & 1+1 시너지 콤보 백과**.

---

## ✨ 2대 핵심 기능

### 1. 🚨 필수 생존 보험 119 (메인 계약 & 함정 분별소)
- **기본 메인 계약이 필수적인 6대 생존 보험**:
  1. **단독 실손의료보험**: 병원비 영수증 70~80% 환급받는 전 국민 기본 안전벨트 (월 1~4만 원)
  2. **비갱신 3대 진단비 종합건강보험**: 일 못할 때 생활비로 쓸 5천만 원 목돈 방패 (월 5~7만 원)
  3. **자동차보험 종합 (대물 10억 + 자상 + 무보험차 5억 + 견인 60km)**: 도로 위 전 재산 파산 방패
  4. **단독 다이렉트 운전자보험 (월 9,900원)**: 12대 중과실/스쿨존 형사합의금 2억 & 구속 방패
  5. **가족일상생활배상책임 (가배책)**: 남의 집 300만 원 누수·접촉사고 배상 (월 800원)
  6. **다이렉트 정기보험 (유자녀 가장 필수)**: 조기 사망 시 유족 생존 자금 1~2억 (월 1~2만 원)
- **❌ 주계약 자체가 함정인 절대 피해야 할 보험 4종**:
  - 종신보험 (저축/연금으로 둔갑) / CI보험 (중대한 질병만 보장) / 치아보험 (장기 유지 시 적자) / 변액·저축성 보험

### 2. 📖 보험 119 위키 & 1+1 시너지 콤보 백과
- **초등 4학년 눈높이(ELI10) 약관 해설**: 어려운 한자어 외계어를 사이다 비유로 1초 만에 해체.
- **설계사 영업 비밀 폭로**: 청약서에 왜 이 특약을 빽빽하게 넣는지 이면의 진실 공개.
- **⭐ 다른 계약과의 1+1 시너지 콤보**:
  - **자상(자동차보험) + 자부상 14급(운전자보험)**: 병원비 100% 무료 처리 + 진단서 1장으로 현금 30만 원 즉시 수령!
  - **가족일상생활배상책임 부부 중복 가입**: 비례분담 원리로 누수 배상 시 자기부담금 0원 마법!
  - **고속도로 도로공사 무료견인(1588-2504) + 보험사 60km 견인**: 사설 렉카 바가지 0원 방어!
  - **실손의료비 + 표적항암약물허가치료비 콤보**: 외래 통원 고액 항암치료비 완벽 방어!
  - **다이렉트 정기보험 + 비갱신 종합보험 분리**: 총 납입 보험료 3,000만 원 절약 콤보!
  - **자동차보험 4대 할인 특약**: Tmap/네이버지도 안전운전(10~16%), 마일리지 환급(15~35%), 블랙박스/ADAS, 만보기 헬스케어.
